# 김건우 | Backend · Systems Integration

**업무 흐름을 이해하고 API·데이터베이스·AI·인프라를 연결해, 실제로 동작하는 시스템을 만드는 데 관심이 있는 개발자입니다.**

Java/Spring Boot 백엔드를 중심으로 권한·업무 상태·외부 API 계약을 다뤄 왔습니다. 새로운 시스템을 구축하고 설정·연동 문제를 로그와 코드로 추적하는 과정에 흥미가 있습니다.

### What I work on

- **Business backend** — Spring Boot, REST API, Spring Security, JPA, 업무 상태·권한 검증
- **System integration** — 외부 AI API, 데이터베이스, 인증·알림·업무 시스템 연계
- **Troubleshooting** — 요청 흐름·설정·로그 분석, 재현 가능한 테스트와 검증
- **AI applications** — Python, LangGraph 기반 Agent 흐름·프롬프트 개선 경험
